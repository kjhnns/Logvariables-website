MCP Server

Connect Variables to Claude Desktop, Cursor, or any MCP-compatible AI agent.
Your agent gets structured, timestamped personal data it can read, write, and reason about.

Installation

No npm install required. Variables hosts the MCP server — just add it to your Claude Desktop config.

Open ~/Library/Application Support/Claude/claude_desktop_config.json (macOS) or %APPDATA%\Claude\claude_desktop_config.json (Windows):

{
  "mcpServers": {
    "variables": {
      "url": "https://app.logvariables.com/mcp/sse",
      "headers": {
        "Authorization": "Bearer vt_your_api_key_here"
      }
    }
  }
}

Get your API key at app.logvariables.com → Settings → API Keys.

Restart Claude Desktop. Done.

Available Tools

Tool Description
variables_list List all tracked variables with recent values. Call this first.
variables_log Log a data point — "slept 7 hours", "mood 8/10", "ran 5k".
variables_query Query values with date range filtering. "Sleep data this week."
variables_summary Natural language summary of recent personal data.
variables_define Create a new variable to track something new.
variables_trend Trend analysis — average, direction, period comparison.

Try it

After setup, open Claude Desktop and ask:

  • "What am I tracking in Variables?"
  • "Log that I slept 7 hours and had 2 coffees"
  • "How's my sleep been trending this month?"
  • "Create a new variable to track meditation minutes"

API Key

Generate your key at app.logvariables.com → Settings → API Keys. Keys start with vt_. Save it somewhere safe — it's shown only once.
