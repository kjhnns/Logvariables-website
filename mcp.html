MCP Server

Variables hosts the MCP server. No local installation required.
Just add a config snippet, restart Claude, and your agent has access to your personal data.

Configuration

Add to your Claude Desktop config
(~/Library/Application Support/Claude/claude_desktop_config.json on macOS,
%APPDATA%\Claude\claude_desktop_config.json on Windows):

{
  "mcpServers": {
    "variables": {
      "url": "https://app.logvariables.com/mcp/sse",
      "headers": {
        "Authorization": "Bearer vt_your_api_key"
      }
    }
  }
}

Get your API key at app.logvariables.com → Settings → API Keys.
Keys start with vt_. Shown once — save it.

Restart Claude Desktop. Done.

Transport

SSE (Server-Sent Events) over HTTPS. No WebSocket. No stdio.
Compatible with any MCP client that supports the SSE transport.

Available Tools

variables_list

Lists all tracked variables with their 5 most recent values.
Call this first to see what data is available.

Parameters: none

Returns:

  • Array of variables, each with: id, name, type, unit, recentValues[]
  • Each recentValue: data, recordDate, createdAt

Example prompt: "What am I tracking in Variables?"

variables_log

Log a new data point for an existing variable.

Parameters:

  • variableId (string, required) — ID of the variable
  • data (string, required) — the value to log
  • recordDate (string, optional) — date in YYYY-MM-DD format, defaults to today

Example prompt: "Log that I slept 7 hours last night"

variables_query

Query values with optional date range and variable filtering.

Parameters:

  • variableId (string, optional) — filter to one variable
  • startDate (string, optional) — YYYY-MM-DD, defaults to 7 days ago
  • endDate (string, optional) — YYYY-MM-DD, defaults to today
  • limit (number, optional) — max results, default 50, max 200

Example prompt: "Show me my sleep data for the past two weeks"

variables_summary

Natural language summary of recent personal data across all variables.

Parameters: none

Returns: A text summary suitable for context injection into an agent's system prompt.

Example prompt: "Give me a summary of how I've been doing"

variables_define

Create a new variable to track.

Parameters:

  • name (string, required) — variable name
  • type (string, required) — number, category, text, boolean, or duration
  • unit (string, optional) — unit of measurement
  • description (string, optional) — what this tracks

Example prompt: "Create a variable to track meditation minutes"

variables_trend

Trend analysis for a variable over a time period.

Parameters:

  • variableId (string, required)
  • period (string, optional) — "7d", "30d", "90d", defaults to "30d"

Returns: average, min, max, direction (up/down/stable), period comparison

Example prompt: "How's my sleep trending this month?"

Troubleshooting

Claude doesn't show MCP connection:

  • Quit and reopen Claude Desktop fully (not just close window)
  • Validate JSON syntax (no trailing commas)
  • Check: is app.logvariables.com reachable in your browser?

"Invalid or missing API key":

  • Verify key starts with vt_
  • Key goes in headers.Authorization, not in env
  • Try generating a new key

Tools not appearing:

  • Give Claude a moment after restart
  • Ask: "What MCP tools do you have available?"
