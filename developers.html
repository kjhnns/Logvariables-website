Connect in 60 seconds

1. Sign up at app.logvariables.com and get an API key (Settings → API Keys)

2. Add to your Claude Desktop config:

{
  "mcpServers": {
    "variables": {
      "url": "https://app.logvariables.com/mcp/sse",
      "headers": {
        "Authorization": "Bearer vt_your_api_key"
      }
    }
  }
}

3. Restart Claude Desktop. Ask: "What am I tracking in Variables?"

That's it.

REST API

Same data, direct HTTP access. For custom integrations, scripts, and non-MCP agents.

Base URL: https://app.logvariables.com
Auth: Bearer token (your API key)

GET
/api/ext/variables/context
List variables + recent values
POST
/api/ext/values
Log a data point
GET
/api/ext/values
Query values (date range, variable filter)
POST
/api/ext/variables
Create a new variable
POST
/api/ext/audio
Voice transcription → auto-log

Example: log a value

curl -X POST https://app.logvariables.com/api/ext/values \
  -H "Authorization: Bearer vt_your_key" \
  -H "Content-Type: application/json" \
  -d '{"variableId": "abc123", "data": "7.5", "recordDate": "2026-03-01"}'
