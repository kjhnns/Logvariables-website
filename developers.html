The problem with AI memory today

Your AI agent is smart but forgetful. Every conversation starts from scratch. ChatGPT Memory stores flat text facts ("user weighs 72kg") — no history, no trends, no types. Mem0 extracts conversation facts into a knowledge graph — great for "what did we talk about," useless for "how has my resting heart rate changed since I started running?"

Personal data isn't a knowledge graph problem. It's a time-series problem with semantic structure.

What Variables provides

Variables is a structured personal data layer. You (or your agent) define typed variables — sleep hours, mood rating, coffee count, running distance, deep work minutes — and log values over time. Every data point is timestamped, typed, and queryable.

Your AI agent connects via MCP (Model Context Protocol) or REST API. It can read your current state, query trends, log new data points, and get natural language summaries of what's been happening in your life.

The result: your AI agent actually knows that you slept 6 hours last night, that your mood has been trending down this week, and that you haven't run since Tuesday. Without you telling it. Every time.

Connect your AI agent in 5 minutes

Step 1

Create a Variables account

Sign up at app.logvariables.com and create a few variables. Start with something simple: sleep_hours, mood, coffee. Log a few data points so your agent has something to work with.

Step 2

Generate an API key

Go to Settings → API Keys and create a new key. Copy it — you'll need it in the next step.

Step 3

Install the MCP server

npm install -g @variables/mcp-server
Step 4

Add to your Claude Desktop config

Open ~/Library/Application Support/Claude/claude_desktop_config.json (macOS) or %APPDATA%\Claude\claude_desktop_config.json (Windows) and add: 

{
  "mcpServers": {
    "variables": {
      "command": "variables-mcp",
      "env": {
        "VARIABLES_API_KEY": "vt_your_api_key_here"
      }
    }
  }
}
Step 5

Restart Claude Desktop

Open Claude and try:

  • "What variables am I tracking?"
  • "Log that I slept 7 hours last night"
  • "How's my sleep been this week?"

That's it. Your AI now has memory.
